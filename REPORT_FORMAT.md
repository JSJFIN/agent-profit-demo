# Standalone report format

The generated HTML is a single UTF-8 document with embedded CSS and JSON. It works from `file://` without a server.

Sections include identity and synthetic warnings; executive profit and cash-flow cards; wallet-balance versus profit reconciliation; revenue, venture, cost, and experiment tables; all submitted events with profit treatment; evidence coverage and warnings; x402 transaction evidence; independent signature status; and deterministic service findings.

The unmodified calculation response is embedded in `<script type="application/json" id="profit-result">`. Separate local artifacts retain the request, response, receipt, analysis, and signed report. Private signed reports and authorization material are ignored by Git.

The renderer performs presentation and counter reconciliation only. It does not recalculate revenue, costs, profit, margins, or analysis findings.
