# Standalone report format

The generated HTML is a single UTF-8 document with embedded CSS and JSON. It works from `file://` without a server.

Sections include identity and synthetic warnings; executive profit and cash-flow cards; wallet-balance versus profit reconciliation; refund-aware customer and experiment economics; complete currency-scoped category costs; unattributed shared costs; all submitted events with profit treatment; evidence coverage and warnings; every x402 transaction and its total; independent signature status; and legible deterministic service findings.

The unmodified calculation response is embedded in `<script type="application/json" id="profit-result">`. Separate local artifacts retain the request, response, receipt, analysis, and signed report. Private signed reports and authorization material are ignored by Git.

The renderer performs presentation, formatting, payment-receipt summation, and counter reconciliation only. It does not reconstruct revenue, costs, experiment contribution, return on spend, profit, margins, or analysis findings.
