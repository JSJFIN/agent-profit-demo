# Objection handling

**“I can read the wallet balance.”** Balance cannot classify owner capital,
withdrawals, internal transfers, refunds, accrued costs, or attribution.

**“My payment processor already reports revenue.”** Revenue alone omits LLM,
hosting, acquisition, paid-tool, and transaction costs.

**“A signed report means audited, right?”** No. It means tamper-evident and
service-signed. Evidence coverage remains explicit.

**“I do not want to retain financial events.”** Use the stateless calculation;
raw events are not retained. Workspaces are optional.

**“Will the SDK spend automatically?”** No. Payment requires explicit opt-in,
signer, profile, recipient, limits, and attempts.

**“Can this file taxes?”** No. It is not statutory accounting or tax software.
